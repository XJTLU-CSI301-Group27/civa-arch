> 1. 演示电脑开启 Docker Desktop（Postgres）。
> 2. 项目根目录运行 `start-civa.bat`（或 `run-backend.ps1`），等到 8080 可用。
> 3. 模拟器/平板安装 `app-debug.apk`（`./gradlew :app:assembleDebug`，或 release 包）。
> 4. 测试账号：`verify_1209` / `Passw0rd2026`（家庭 `OurHome`，已有 9 个冰箱批次、若干家庭菜谱、1 条食记、做饭历史）。
>    第二账号可现场注册，用于家庭邀请/共享验证。
>
> 每项检查后打勾；如不通过，记录步骤、截图/日志和版本。

## A. 启动与导航

- [ ] A1 首次启动有开场动画（约 6.6 秒），不崩溃；结束后出现「一起吃好每一天」登录页。
- [ ] A2 竖屏（手机/平板竖放）显示底部 5 个入口：今天 / 菜谱 / 冰箱 / 食记 / 我的。
- [ ] A3 横屏（手机或平板横放）自动切换为**左侧导航栏**，底部导航隐藏；旋转回竖屏恢复底部导航。
- [ ] A4 旋转/分屏后当前页面和已选日期保持，不崩溃、不重复提交。
- [ ] A5 登录/注册页不自动弹出键盘；键盘弹出时仍能完成输入与提交。

## B. 账号

- [ ] B1 注册新账号（用户名/显示名/密码）成功，自动登录。
- [ ] B2 错误密码提示「用户名或密码不正确」，不崩溃。
- [ ] B3 退出登录后回到登录页，再登录可恢复数据（个人菜谱、食记）。
- [ ] B4 换账号后看不到上一个账号的个人菜谱/食记/计划。

## C. 家庭

- [ ] C0 两个账号加入同一家庭后，「我的」页家庭成员列表显示各自**显示名与 @用户名**；修改自己的显示名后，另一账号刷新能看到新名字。
- [ ] C0b 家庭计划中每道菜显示“由 X 添加”（最后编辑人）；不同成员编辑同一餐次后名字更新。
- [ ] C1 「我的 → 家庭设置」显示真实家庭名（`OurHome`）、固定邀请码（26 位，可复制）。
- [ ] C2 修改家庭名并保存，返回「我的」后显示新名字。
- [ ] C3 用第二账号输入邀请码加入家庭，双方在成员列表/家庭设置中可见。
- [ ] C4 普通成员也能修改家庭名（全员平等）。
- [ ] C5 退出家庭后，个人菜谱/食记保留；家庭共享内容不可再访问。
- [ ] C6 最后一名成员退出后家庭被注销，随后可重新创建/加入。
- [ ] C7 非成员无法读取该家庭计划/菜谱/冰箱（用第三账号验证，接口返回 404）。

## D. 今天（个人排餐草稿）

- [ ] D1 今天页显示日期、早餐/午餐/晚餐三个卡片；「加道菜」可用。
- [ ] D2 加菜：我来决定吃什么 → 输入菜名 → 就它啦，卡片出现该菜。
- [ ] D3 加菜：想不出来，饿饿 → 选口味/荤素/时间 → 开盲盒 → 就是这个啦，卡片出现推荐菜。
- [ ] D4 点日历切换日期，可加未来日期的菜；切换回来后菜还在。
- [ ] D5 点已有菜卡片，弹出「菜谱 / 热量 / 移除」；移除后卡片消失。
- [ ] D6 创建/加入/退出家庭后，今天的三餐**不会消失**（计划按账号保存）。
- [ ] D7 今天页右上角「计划」按钮进入家庭计划页。

## E. 菜谱

- [ ] E1 菜谱页四个来源：公共 / 我的 / 家庭 / 想吃，可切换。

- [ ] E3 公共详情：食材/做法/营养、想吃、保存到我的菜谱、加入家庭（缺字典食材时给出提示）。

- [ ] E5 家庭：列表、新建家庭菜谱（标准食材）、编辑、归档/恢复、确认做饭。
- [ ] E6 想吃：显示已收藏的菜，点进去可取消想吃；空状态文案正常。
- [ ] E7 菜谱页快速切换 Tab/旋转不崩溃（历史闪退修复回归项）。

## F. 冰箱

- [ ] F1 冰箱显示批次（食材名/数量/单位/到期日）；可按全部/未过期/临期/已过期筛选。
- [ ] F2 添加食材（名称/数量/单位/位置/到期日）后列表出现新批次。
- [ ] F3 消耗/丢弃：数量减少，操作记录在流水中；库存不会变负数。
- [ ] F4 扣到 0 的批次从冰箱列表消失（流水仍保留）。
- [ ] F5 临期/过期批次不作为可用库存推荐；未知到期日明确显示"未知"。
- [ ] F6 数量修正原因可选；单位不兼容有提示。

## G. 食记（本周重点）

- [ ] G1 食记页显示月历，可上月/下月/回到今天；有记录的日期有标记。
- [ ] G2 点日期显示当日记录；月/日热量汇总显示「已记录 X kcal · 另有 N 条未估算」。
- [ ] G3 记一餐 → 选「在外面吃」：自由输入菜名/份量/热量/备注，保存成功并出现在当日列表。
- [ ] G4 记一餐 → 选「在家吃（用冰箱食材）」：列表只展示**冰箱现有批次**，勾选并填用量后保存：
  - 冰箱对应批次数量减少；
  - 生成一条食记（备注含本次食材清单）；
  - 热量来自服务端估算；Key 不可用时显示「未估算」而不是 0。
- [ ] G5 「今天的计划」区块显示「今天」页安排的菜；点「吃了」：
  - 家庭有同名菜谱且库存够 → 自动扣冰箱 + 生成做饭历史 + 自动记一餐，计划行标记「（已记餐）」；
  - 库存不足 → 弹窗列出「缺少：食材（需 X，现有 Y）」，可取消或「仍记一餐」（只记食记不扣库存）；
  - 家庭没有同名菜谱 → 提示只能记一餐、不扣库存。
- [ ] G6 点击已有食记可修改（名称/份量/热量/备注）或删除；删除不影响库存。
- [ ] G7 「家里最近做的菜」显示做饭历史（日期/菜名/份数），点一条可预填记一餐。
- [ ] G8 补录过去日期的食记、跨月查看、周/月汇总数字正确。
- [ ] G9 未来日期不能记录实际用餐（可查看计划，不产生食记）。
